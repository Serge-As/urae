# ECO-SYSTEM — SUPPLÉMENT D'EXÉCUTION COMPLETE APP 1.0.0

## Décision
L'ancienne Alpha 0.5/0.6 est superseded comme cible visible. Elle reste sauvegarde et source de moteurs canoniques.

## Prompt Maître appliqué
Exécuter les lots A→J sans démo jetable :
A Cloud/D1 ; B Identity/Discovery/Membership ; C Group Launch/Rubrics ; D Session Command Center ;
E Ledger/prêts/solidarité ; F communauté/économie ; G AdManager ; H Academy/ONG/IA/Safety/Paper ;
I exports/dashboards/intégrations ; J hardening/pilote.

## Complétude structurelle
Toute capacité connue a une place visible et un statut réel. Les capacités dotées d'un moteur spécialisé l'utilisent.
Les autres disposent d'un Workspace universel persistant permettant dossier, suivi, statut, résumé et audit,
sans prétendre que leur moteur spécialisé final est terminé.

## Living Rules
La réalité d'un groupe est paramétrable, versionnée et auditable. Règle écrite, pratique observée et règle opérationnelle validée ne sont pas fusionnées.

## Interdiction de fausse complétude
La présence dans le catalogue ou le Workspace ne permet pas de marquer automatiquement une capacité `VERIFIED_REMOTE` ou `PILOT_VALIDATED`.

## Identité exécutable et sécurité
- Ligne produit : `1.0.0-complete-app`.
- Invariant de sécurité : `realMoneyEnabled=false` jusqu'à autorisation distincte.
