# ECO-SYSTEM — ADDITIF CONSTITUTIONNEL 1.4.1
## Accueil, Séances, intégrité terrain et réintégration de la vision historique

**Date : 19 septembre 2026**  
**Statut : additif au Cahier Maître 3.2.0 ; ne remplace pas le socle 2.3.4 ni les acquis 1.4.0.**

# 1. Règle de priorité
La gestion des groupes reste le premier socle. Les nouveaux univers économiques, sociaux et commerciaux doivent réutiliser les mêmes owners de groupe, identité, règles, finance, séance, preuve et notification.

# 2. Accueil Groupe
L'Accueil est la synthèse contextualisée du groupe et non un second moteur :
- identification + code ECO-GRP ;
- déclaration/mandat lorsqu'ils sont renseignés ;
- exercice/cycle ;
- Bureau ;
- membres ;
- précédente/actuelle/prochaines séances ;
- finance Ledger/Récap ;
- dettes ;
- classements Tontine ;
- bénéficiaires ;
- présence ;
- actions selon rôle.

# 3. Accueil Membre
Un membre voit :
- identité groupe + propre identité d'adhésion ;
- propre situation ;
- propres dettes ;
- propres participations/bénéfices ;
- propre présence ;
- simulations autorisées ;
- validations/réserves.
Les données globales financières ou privées des autres membres ne sont jamais une simple variante d'affichage : elles sont filtrées par le service canonique.

# 4. Séance
Une séance est l'unité opérationnelle reliant :
- date/lieu/thème/tenue ;
- matrice financière ;
- caisse ;
- Back-office ;
- créances ;
- présence ;
- bénéficiaires ;
- preuves ;
- précédente/suivante ;
- historique.

# 5. Preuve de réception
Pour toute somme/bénéfice remis :
- bénéficiaire déclaré ;
- contexte groupe/séance/rubrique/membre/montant ;
- code non secret ;
- preuve par self-confirm, papier ou document ;
- stockage privé si fichier ;
- Evidence immuable ;
- audit ;
- aucune suppression silencieuse.

# 6. Correction financière
Toute correction :
- conserve l'original ;
- crée reversal/compensation ;
- conserve nouvelle valeur ;
- motif ;
- auteur ;
- revue indépendante obligatoire ;
- auteur jamais son propre réviseur ;
- réserve membre indépendante de la vérité comptable.

# 7. Offline
Le hors-ligne est un mode dégradé honnête :
- snapshot daté ;
- intentions en attente ;
- aucun faux succès serveur ;
- resynchronisation idempotente.

# 8. Voix
La dictée financière ne contourne jamais preview/validation. Une faible confiance bloque le remplacement automatique d'un montant numérique.

# 9. Gestion destructive
Les demandes historiques « supprimer membre/rubrique » sont interprétées de manière compatible avec l'audit :
- membre → départ/suspension/lifecycle ;
- rubrique → archivage ;
- suppression physique uniquement si aucune dépendance métier/probatoire ne l'interdit.

# 10. Réintégration vision
Sont explicitement conservés :
- ingénierie des Associations/Tontines ;
- ingénierie sociale/financière/économique ;
- prospérité ;
- développement des compétences ;
- bien-être ;
- partage ;
- anti-arnaques / anti-Ponzi ;
- outils technologiques avancés ;
- information avec provenance.

Ces notions n'autorisent pas des moteurs parallèles. Elles enrichissent Group Core, Trust, Academy, Discovery, Marketplace, Eco Business, Opportunity Graph, Anticipation et SAFETY.ANTISCAM.

# 11. Information et buzz
La partie utile de l'idée historique est :
- source ;
- auteur ;
- preuve ;
- niveau de vérification ;
- distinction information/opinion/tendance/sponsorisé ;
- modération.
Une tranche horaire n'est jamais utilisée comme critère intrinsèque de vérité.

# 12. Statut
Les capacités nouvelles 1.4.1 restent FUNCTIONAL_BETA jusqu'à recette terrain ; le Labo financier anti-Ponzi reste STRUCTURAL_V1 jusqu'à implémentation et qualification dédiées.
