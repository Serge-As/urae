# ECO-SYSTEM — COMPLETE APP 1.0.0

Cette ligne remplace l'ancienne Alpha comme cible produit visible.

## Principe
Chaque capacité du Cahier Maître doit être visible, localisable et utilisable dans une interface cohérente.
Une capacité dotée d'un moteur canonique spécialisé l'utilise directement.
Une capacité encore en maturation utilise le Workspace universel persistant sans créer de moteur métier concurrent.

## Living Rules
« Voilà comment un groupe peut décrire la manière dont sa collation fonctionne. »

L'application distingue :
1. règle écrite ;
2. pratique observée ;
3. règle opérationnelle validée ;
4. exceptions autorisées ;
5. autorités requises ;
6. trace d'audit.
