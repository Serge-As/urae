# ECO-SYSTEM — Modèle Économique Détaillé 3.1.0

Date : 2026-09-16  
Statut : hypothèses commerciales à tester ; aucune tarification n'est figée dans le code.

## 1. Doctrine

Le cœur de gestion d'un groupe reste gratuit autant que possible. Les acteurs qui capturent une valeur économique directe financent prioritairement la plateforme : fournisseurs, partenaires, ONG, structures multi-groupes, annonceurs et utilisateurs professionnels de capacités avancées.

Ne jamais paywaller : sécurité, consultation de sa situation, correction d'erreur, preuve transactionnelle, réserve sur transaction, export minimal.

## 2. Rails de revenus

- Groupe Plus / Pro : automatisations, rapports, stockage, support, Live avancé.
- Multi-groupes : supervision/délégation.
- Marketplace / Deals : commission ou forfait uniquement si valeur transactionnelle mesurable.
- Leads vérifiés : CPA/forfait.
- AdManager : CPM/CPC/CPA avec privacy budget/frequency cap.
- ONG / programmes : contrat programme/cohorte/reporting.
- Insights Pro : données agrégées et gouvernées.
- Live/médias : add-on si coûts variables.
- Formation/support : forfait.

## 3. Hypothèses tarifaires à tester — Cameroun

Ces montants ne sont pas des tarifs décidés :
- Community : 0 F ;
- Groupe Plus : 1 000–2 500 F/mois ;
- Groupe Pro : 2 500–7 500 F/mois ;
- Multi-groupes : 10 000–50 000 F/mois ;
- Formation Bureau : 5 000–50 000 F/session ;
- Programme ONG : 50 000–500 000+ F/mois ;
- campagne locale : à partir de 5 000–10 000 F ;
- lead : 100–2 000 F selon valeur ;
- Deal/Marketplace : ordre de grandeur 1–5 % du GMV si Eco-System crée/capture la transaction.

## 4. Marketplace / Demand Exchange

Agrégation de demandes fragmentées :
signal → appel d'offre → comparaison prix rendu/capacité/délai/fiabilité → seuil → deal → commande/livraison/confirmation.

Monétisation : forfait fournisseur, commission ou sponsoring transparent.

## 5. AdManager

Signaux autorisés : contexte public, localité grossière, intérêt produit explicite, interaction commerciale.
Interdits : dettes, soldes, CNI, téléphone, santé, litiges, biométrie.

Mécanismes : privacy budget, frequency cap, quality score, pacing, attribution.

## 6. ONG / partenaires

Pack Programme, Pack Formation, Pack Reporting, API/Insights agrégée.
Le contrat porte sur le programme et la valeur d'exécution, pas sur la revente de fiches membres.

## 7. Unit economics

Mesurer : marge, marge %, CAC, LTV, payback, coût/groupe actif, coûts D1/R2/DO/IA/vidéo/SMS.

Control Center doit remonter les seuils et coûts avant blocage ou déficit.

## 8. Fidélisation des jeunes

Rétention par utilité :
- brouillons/lecture multi-appareils ;
- voix, réactions, threads, sondages ;
- Live interactif ;
- événements ;
- deals utiles ;
- entraide/services locaux ;
- réputation sur actes utiles vérifiés, jamais richesse/dette.

## 9. Innovations économiques

- Group Procurement Pass ;

## 10. Paiements / réglementation

Pas de wallet, séquestre, crédit, assurance ou collecte réglementée improvisés. Les rails financiers avancés passent par partenaires qualifiés et revue juridique dédiée.

## 11. KPI

Produit : activation/rétention/groupes actifs.  
Qualité : incidents/temps résolution/PASS-DEGRADED-FAIL.  
Économie : revenu par rail/marge/coût par groupe.  
Marketplace : demandes/GMV/conversion/litiges.  
Ads : action rate/feedback/fréquence/revenu.  
ONG : programmes/groupes/jalons/renouvellement.  
Communauté : retour Forum/événements/opt-out.

## 12. Phases

E0 : gratuit fonctionnel + mesure coûts + pilotes.  
E1 : Deals/coupons/reverse auction/preuves conversion.  
E2 : partenaires marchands/réservation/acompte qualifiés.  
E3 : Insights B2B/Partner SaaS/Ad billing.  
E4 : marketplace multi-fournisseurs/logistique/produits financiers seulement avec partenaires.

## 13. Décisions maintenant

1. Ne pas fixer un tarif définitif avant 3–5 cohortes.
2. Garder cœur gestion + sécurité gratuit.
3. Mesurer coût par groupe/fonction.
4. Prioriser ONG/partenaires/achats groupés.
5. Introduire Pro quand la valeur est tangible.
6. AdManager = financement secondaire, pas dépendance.
7. Faire payer Live/vidéo avancé si coût réel important.
8. Construire attribution Marketplace avant commission.
